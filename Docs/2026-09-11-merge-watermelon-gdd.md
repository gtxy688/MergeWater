# 《合成果园》策划案（暂定名）

- 日期：2026-09-11　版本：v0.1（MVP 策划）
- 品类：竖屏 2D 休闲·投放堆叠合成（合成大西瓜 like）
- 平台：微信小游戏（优先），抖音小游戏（同构复用）
- 面向：作品集 Demo + 可扫码试玩；不接支付、不强求上架

## 0. 一句话卖点

「**一拉一放，水果连环爆**」：3 秒上手、30 秒出连击爽点、3 分钟一局，输了还想再来一局。

## 1. 立项与体验目标

- 目标用户：碎片时间玩家、通勤/睡前；轻竞技（好友排行）与轻解压（合成爽感）。
- 竞品参照：合成大西瓜（合成爽感）× 2048（等级爬升）× 泡泡龙/弹珠（落点决策）。
- 体验目标：3 秒懂、首局 60 秒内出现第一次「≥4 连击」、单局 2–4 分钟、失败有明确「差一步」感。

## 2. 核心玩法

### 2.1 核心循环

按住拖动选落点 → 松手投放 → 物理堆叠 → 同级相撞合成更大 → 连锁连击加分 → 空间被压缩 → 越线失败 → 复活/结算 → 再开一局。

### 2.2 操作

- 按住：出现落点预览线（抛物线 + 反弹预演 0.8s）。
- 拖动：水平选择落点 x；松手投放。
- next：右上角预览下 1 颗水果。

### 2.3 规则

- 合成：相同等级相撞 → 合成更高一级；最高级（西瓜）不再合成。
- 连击：3 秒内连续合成连击 +1；倍率 = 1 + 0.1×(连击 − 1)，封顶 2.0。
- 失败：任一「已静止」水果持续越过警戒线 1.2s 判负（缓冲防误杀）。
- 复活：每局限 1 次，看激励视频清除最高一簇（≤3 颗，优先高等级）。

## 3. 数值设计（初值，可调）

### 3.2 节奏与难度

- 前 20 投：只出 1–2 级，快速第一次合成建立正反馈。
- 20–60 投：引入 3 级，连击窗口更易达成，冲首个 4 连击。
- 60 投后：空间压缩为主难度；不改物理，不改概率（保持公平与可复现）。

### 3.3 道具与两侧广告入口（控范围：4 种能力）

- 清屏（原「撤销」，2026-09-13 改写 R11）：一次性清空全场水果。每日领取上限 3。
- 炸弹：清除指定点半径 0.6m 内水果。每日上限 3。
- 锤子：定点敲碎「单个指定水果」（长按瞄准出现落点圈，松手生效）。每日上限 3。
- 摇一摇（重排）：观看激励视频后触发一次「轻摇重排」——对全屏水果施加小幅随机冲量使其重新落位，可能促成新合成，但不直接消除。每日限 2 次。
- 获取：撤销/炸弹/锤子经两侧「免费」入口看激励视频 ×1/个，或分享助力 ×1/个；摇一摇仅看激励视频。使用即时、无冷却。

### 3.4 商业化点位与频次（合规优先）

- 激励视频点位：失败复活（每局限 1，全局冷却 90s）；两侧「免费」道具入口（撤销/炸弹/锤子，每类每日 ≤3）；摇一摇（每日 ≤2）；大礼包（每日 1 次，看广告得道具组合）。
- 插屏：仅在结算页、每 3 局至多 1 次（可远程开关）。
- 明确不做：底部 Banner 与信息流广告、交叉推广/导流位（参考图右侧「上头消不停」类）。
- 说明：个人主体未达流量主门槛，用测试广告位 + 频次控制设计，面试如实说明。

## 4. 系统闭环（局内 → 局外）

局内合成爽感 → 破纪录/连击 → 分享挑战/好友排行 → 道具与复活 → 再开一局。

- 好友排行（开放数据域）：按最高分，每页 20 条；被超越触发红点与召回文案。
- 裂变：助力得道具、发起「连击挑战」卡片（带当期分数与口令）。
- 召回（可选）：订阅消息「你的纪录被 @好友 超越」。

## 5. 手感与表现需求（给区间，便于调）

- 投放：橡皮筋回弹 + 松手音；生成瞬间轻震屏 0.05s。
- 合成：吸附 60ms → 爆点粒子 → 慢放 timeScale 0.2/0.15s → 顿帧 80–120ms 随连击递增。
- 连击：音阶上行（+1 半音/连击，封顶 8 度）；震屏 3 档；飘字 punch。
- 越线：警戒线红色脉冲 + 心跳音；失败重震 0.2s。
- 美术：Q 版水果、明亮高饱和、圆角 UI；音频：轻快 BGM 1 首 + SFX 10 个内（清单见 §11）。

## 6. UI/交互

### 6.1 进入流程（无独立开始页）

启动（Logo + 分包加载进度）→ 首启「隐私政策」弹窗（同意后才初始化上报与 SDK）→ **直接进入对局**。

- 取舍：不做主页，减少一次点击、贴合秒开与即玩；主页职能并入对局 HUD 与结算页。
- 入口落位：设置 = HUD 右上（系统胶囊左侧）；好友排行/分享挑战 = 结算页 + HUD 角标；道具/大礼包 = 两侧入口；登录授权后置到首次使用排行/分享时触发。
- 页面流转：对局(HUD) → 结算 →（排行 / 分享挑战 / 道具背包 / 设置）→「再来一局」直开新局。

### 6.2 对局 HUD 布局（对齐参考图）

- 顶栏：左侧「最高分：N」；中央大号当前分，其下「阶段目标进度条」（到达里程碑分给一次性道具，节点可配，如 200/500/1000）；右侧设置齿轮——置于顶部右侧、系统胶囊左侧，避免遮挡微信胶囊。
- 顶部中央：待投水果居中展示，正下方垂直虚线落点；按住拖动选 x，松手投放。
- 左侧入口（上→下）：摇一摇（看视频重排，角标摄像机）、锤子·免费、大礼包（每日可领取）。
- 右侧入口（上→下）：撤销·免费、炸弹·免费。
- 底部：不放任何 Banner/信息流广告。
- 警戒线：顶部下方横线，越线红色脉冲。

### 6.3 设置面板

音效/音乐/震动开关、隐私政策、用户协议、实名/防沉迷入口说明、清除缓存、版本号。

### 6.4 红点规则

可领取（道具/大礼包）、被超越；进入对应页即清除。

## 7. 平台与合规

- 登录：wx.login；无后端用匿名 ID，接口预留。
- 分享：主动（助力/挑战）+ 被动；回调不可信，按「发起即记录 + 60s 冷却」。
- 排行：开放数据域（主/子域）。
- 合规：隐私政策页、实名/防沉迷入口说明、适龄提示；不接支付。

## 8. 数据埋点与指标

- 事件：启动、首投、每次合成(tier/连击)、越线开始/结束、复活点击/完成、分享发起、排行查看/翻页、道具领取/使用、结算；两侧入口点击与广告完成（摇一摇/锤子/撤销/炸弹/大礼包）、阶段目标达成、设置开关变更。
- 指标：次留/3 留、单局时长、人均局数/日、首次 4 连击出现时间、广告展示率与完成率、分享率、K 因子、排行榜渗透。
- 北极星：次留；护栏：广告完成率不恶化次留。

## 9. 新手引导

- 第 1 局：动态箭头引导「按住拖动—松手」；第一次合成高亮；越线前脉冲预警。
- 前 3 局：结算页固定引导「分享挑战」与「好友排行」。

## 10. 版本规划

- MVP：核心循环 + 手感 + 本地排行 + 测试激励视频 + 隐私合规。
- V1：开放数据域好友排行 + 分享挑战/助力 + 红点。
- V1.1：订阅召回 + 点位 AB（复活冷却/插屏频次）+ 数据看板。

## 11. 资源清单（最小集）

- 美术：10 级水果各 1（512px，打图集）、背景 1、警戒线 1、按钮/弹窗若干、粒子贴图 3；道具与入口图标（撤销/炸弹/锤子/摇一摇/大礼包）+ 摄像机角标。**等级数与美术资源对齐**（2026-09-13：由 11 级下调为 10 级）。
- 音频：BGM 1、SFX（投放/合成/连击上行/越线心跳/失败/按钮/领取/复活）≤10。
- 字体：1 款圆体（注意商用授权）。

## 12. 验收标准（体验口径）

- 3 秒内理解操作；首局 60 秒内出现 ≥4 连击；单局 2–4 分钟。
- UI 口径：顶栏（最高分/当前分/阶段进度/设置）、两侧广告入口、中央投放虚线齐备；底部无 Banner/信息流，无交叉推广位。
- 中端真机稳定 60fps；复活/分享/排行/合规流程可演示；可扫码试玩。

## 13. 风险与对策

- 堆叠抖动/穿隧 → 圆碰撞、CCD、限速与睡眠阈值、压测回归。
- 流量主未开通 → 测试广告位 + 频次设计，面试如实说明。
- 分享回调不可信 → 发起即记录 + 冷却防刷，文案不做「必得」承诺。
- 个人主体限制 → 不接支付，目标为可运行 Demo + 预览。
