# 《合成果园》MergeWater 需求文档

> 本文件定义产品行为、约束、数值和验收目标。与架构、代码或测试证据不一致时，先报告冲突；裁定后同步相关内容。

> 更新日期：2026-09-11

## 项目定位

- 一句话：一拉一放、水果连环爆的竖屏 2D 投放堆叠合成游戏（合成大西瓜 like）。
- 目标用户：碎片时间玩家、通勤/睡前；轻竞技与轻解压诉求。
- 目标平台与设备：微信小游戏优先，抖音小游戏同构复用；竖屏；中端机稳定 60fps。
- 输入方式：单指按住拖动选落点、松手投放（触屏优先级最高，Editor 内用鼠标模拟）。
- 项目目标：可运行、可扫码试玩的 MVP 作品集 Demo；不接支付、不强求上架。

## 核心循环

按住拖动选落点 → 松手投放 → 物理堆叠 → 同级相撞合成更大 → 连锁连击加分 → 空间被压缩 → 越线失败 → 复活/结算 → 再开一局。

## 功能与验收目标

| 编号 | 功能 | 目标行为 | 优先级 | 可观察的验收结果 |
|------|------|----------|--------|------------------|
| R1 | 按住拖动瞄准 | 按住时出现落点预览（抛物线 + 反弹预演 0.8s 内）；拖动只改变落点 x，超出场地范围时被夹取 | P0 | 按住任意位置都出现预览线；拖动时预览随手指水平移动；松手后预览消失 |
| R2 | 松手投放 | 松手在落点 x 生成当前待投水果，水果在重力下自由下落并堆叠 | P0 | 每次松手恰好生成 1 颗水果；生成后 next 队列前移 |
| R3 | 同级相撞合成 | 两颗相同等级水果碰撞 → 在碰撞位置合成更高一级；最高级（大西瓜）不再合成 | P0 | 两个同级水果相撞后原两颗消失、生成 1 颗高一级水果；11 级相撞不产生新水果 |
| R4 | 得分 | 每次成功合成按目标等级得分配置加分，11 级为大西瓜顶点分 | P0 | 合成后当前分按 V2.3 表增加；分数只增不减 |
| R5 | 连击与倍率 | 3 秒内连续合成连击 +1；倍率 = 1 + 0.1×(连击−1)，封顶 2.0；超时连击归零 | P0 | 3 秒内二次合成飘字显示更高倍率；单次合成得分 = 等级分 × 当前倍率 |
| R6 | 越线判负 | 任一「已静止」水果持续越过警戒线 1.2s 判负（静止判定缓冲，防误杀） | P0 | 水果短暂弹过警戒线不判负；静止越线满 1.2s 触发失败流程 |
| R7 | 复活 | 每局限 1 次；观看激励视频后清除最高一簇（≤3 颗，优先高等级），清除后可继续 | P0 | 失败页点复活 → 播放激励视频 → 成功后顶部最高且连成簇的水果被移除、回到对局；第 2 次复活不可用 |
| R8 | next 预览 | 右上角预览下 1 颗水果等级 | P1 | 投放后预览更新为新队列头 |
| R9 | 待投等级节奏 | 前 20 投只出 1–2 级；20–60 投引入 3 级；投放权重按 V2.4，60 投后不改概率 | P1 | 记分板显示投数；累计投数 <20 时只出现 1/2 级 |
| R10 | 阶段目标进度条 | 顶栏当前分下方显示阶段目标进度；到达里程碑分发放一次性道具 | P1 | 达到 200/500/1000 分时进度条推进且对应道具数量 +1，里程碑只发放一次 |
| R11 | 道具·撤销 | 移除「最后一次投放且未参与合成」的水果；每日领取上限 3 | P1 | 使用后最后一颗未合成水果消失，分数与合成历史不变；未满足条件时不可用 |
| R12 | 道具·炸弹 | 清除指定点半径 0.6m 内水果；每日上限 3 | P1 | 瞄准点出现落点圈，松手后范围内水果被移除 |
| R13 | 道具·锤子 | 定点敲碎单个指定水果（长按瞄准出现落点圈，松手生效）；每日上限 3 | P1 | 命中范围内最高/最近的一颗被移除，其余不受影响 |
| R14 | 道具·摇一摇 | 观看激励视频后对全屏水果施加小幅随机冲量重排，不直接消除；每日限 2 次 | P1 | 使用后所有水果发生可见位移并可能产生新合成，无水果被直接移除 |
| R15 | 道具获取 | 撤销/炸弹/锤子经两侧「免费」入口看激励视频 ×1/个或分享助力 ×1/个；摇一摇仅看激励视频；使用即时、无冷却 | P1 | 观看完成后对应道具 +1 并写入存档；分享助力按「发起即记录 + 60s 冷却」处理 |
| R16 | 激励视频点位 | 失败复活（每局限 1、全局冷却 90s）、两侧免费道具入口（每类每日 ≤3）、摇一摇（每日 ≤2）、大礼包（每日 1 次，看广告得道具组合） | P1 | 各点位按冷却与每日上限放行/拒绝；被拒绝时给出可读原因 |
| R17 | 插屏广告 | 仅结算页，每 3 局至多 1 次，可远程开关 | P2 | 连续 3 局内结算页出现至多 1 次插屏；开关关闭时不出现 |
| R18 | 本地排行榜 | 按最高分排名，本地存储，显示前若干条；MVP 不接开放数据域好友 | P1 | 破纪录后排行榜第一名更新为当前分数 |
| R19 | 分享挑战 | 生成「连击挑战」文案（带当期分数与口令），可在结算页发起 | P2 | 发起后记录分享事件，60s 内重复发起被冷却拦截 |
| R20 | 隐私合规 | 首启「隐私政策」弹窗；同意后才初始化上报与 SDK；设置页含隐私政策、用户协议、实名/防沉迷入口说明、清除缓存、版本号 | P0 | 首次启动必现弹窗；不同意时埋点/SDK 不初始化；同意后可进入对局 |
| R21 | 红点规则 | 可领取（道具/大礼包）、被超越显示红点；进入对应页即清除 | P2 | 存在可领取项时入口显示红点，进入后红点消失 |
| R22 | 手感与表现 | 投放橡皮筋回弹 + 松手音；生成瞬间震屏 0.05s；合成吸附 60ms → 粒子 → 慢放 0.2×/0.15s → 顿帧 80–120ms 随连击递增；连击音阶上行（+1 半音，封顶 8 度）、震屏 3 档、飘字 punch；越线红色脉冲 + 心跳音，失败重震 0.2s | P1 | 每次合成可观察到吸附、粒子、慢放与顿帧；连击越高顿帧/震屏越强、音高越高 |
| R23 | 新手引导 | 第 1 局动态箭头引导「按住拖动—松手」；第一次合成高亮；越线前脉冲预警；前 3 局结算页固定引导「分享挑战」与「好友排行」 | P1 | 首局出现箭头与高亮；越线前出现预警；前 3 局结算页出现分享/排行引导 |
| R24 | 数据埋点 | 启动、首投、每次合成(tier/连击)、越线开始/结束、复活点击/完成、分享发起、排行查看/翻页、道具领取/使用、结算、两侧入口点击与广告完成、阶段目标达成、设置开关变更 | P2 | 每个事件可在编辑器日志或本地事件日志中观察到，含事件名与关键参数 |

### V3 非功能要求

- 性能预算：中端真机稳定 60fps；单局水果实例数上限 120（超出视为异常并记录告警）。
- 物理稳定性：圆碰撞 + 连续碰撞检测（CCD）+ 限速 + 睡眠阈值；不得出现持续抖动或穿隧（GDD §13）。
- 存档与兼容：本地存档带 schema 版本号，旧版本可迁移；损坏存档回退默认值不崩溃。
- 网络与离线：MVP 全离线可玩；广告与分享为可降级的外部依赖，缺失时游戏仍可完整游玩。
- 可访问性与本地化：中文界面；圆角 UI；色弱可辨（水果颜色 + 半径双重区分）。
- 合规：隐私政策页、实名/防沉迷入口说明、适龄提示；不接支付。

## 操作与交互

| 场景 | 输入 | 行为 | 反馈 | 失败或边界行为 |
|------|------|------|------|----------------|
| 对局·瞄准 | 按住屏幕 | 显示落点预览线与反弹预演 | 预览线出现 | 按住不动仅显示预览，不消耗水果 |
| 对局·拖动 | 水平拖动 | 落点 x 跟随手指 | 预览线随手指移动 | 超出场地 x 范围时夹到边界，不越界 |
| 对局·投放 | 松手 | 在落点 x 生成当前水果 | 生成瞬间震屏 0.05s + 松手音 | 松手位置即最终落点；生成后进入冷却直到可再次瞄准 |
| 对局·合成 | 同级碰撞 | 合成高一级并加分 | 吸附 60ms → 粒子 → 慢放 → 顿帧 → 飘字 | 11 级相撞只产生碰撞反馈，不合成、不加分 |
| 对局·失败 | 静止水果越线满 1.2s | 进入失败流程 | 警戒线红色脉冲 + 心跳音 + 重震 0.2s | 越线后回到线下则计时清零 |
| 对局·复活 | 失败页点复活 | 播放激励视频，成功则清除最高一簇并续玩 | 广告播放 UI → 清除反馈 | 已用 1 次 / 全局冷却 90s 内 / 广告失败时按钮禁用并说明 |
| 对局·道具使用 | 点两侧入口后选点 | 按道具类型作用于场地 | 落点圈 + 生效特效 | 数量为 0 时不可用；瞄准中可取消 |
| 结算 | 失败或主动结束 | 显示分数、最高分、排行、分享挑战、再来一局 | 结算页 + 可选插屏 | 插屏按 V2.16 频次与开关决定是否出现 |
| 首次启动 | 启动完成 | 弹出隐私政策 | 隐私弹窗 | 不同意则停留并禁用上报/SDK，可退出 |
| 设置 | 点 HUD 齿轮 | 打开设置面板 | 面板与开关 | 开关即时生效并持久化 |

## 范围外

- 支付、内购、礼包购买（个人主体限制，明确不做）。
- 底部 Banner、信息流广告、交叉推广/导流位（GDD §3.4、§6.2）。
- 独立开始页/主页（GDD §6.1 取舍：不做主页）。
- MVP 内的开放数据域好友排行、订阅消息召回、AB 实验与数据看板（属 V1/V1.1）。
- 真实微信 SDK 接入与真实激励视频；MVP 使用可替换的测试广告适配器与本地排行（GDD §10）。
- 服务器权威存档与账号体系；无后端时使用匿名 ID，仅预留接口。

## 已确认决策

| 编号 | 决策 | 原因 | 影响的需求 | 日期 |
|------|------|------|------------|------|
