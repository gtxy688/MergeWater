> 本文件定义产品行为、约束、数值和验收目标。与架构、代码或测试证据不一致时，先报告冲突；裁定后同步相关内容。

## 项目定位

- 一句话：一拉一放、水果连环爆的竖屏 2D 投放堆叠合成游戏（合成大西瓜 like）。
- 目标用户：碎片时间玩家、通勤/睡前；轻竞技与轻解压诉求。
- 目标平台与设备：微信小游戏优先，抖音小游戏同构复用；竖屏；中端机稳定 60fps。
- 输入方式：单指按住拖动选落点、松手投放（触屏优先级最高，Editor 内用鼠标模拟）。
- 项目目标：可运行、可扫码试玩的 MVP 作品集 Demo；不接支付、不强求上架。

## 核心循环

按住拖动选落点 → 松手投放 → 物理堆叠 → 同级相撞合成更大 → 连锁连击加分 → 空间被压缩 → 越线失败 → 复活/结算 → 再开一局。

| R3 | 同级相撞合成 | 两颗相同等级水果碰撞 → 在碰撞位置合成更高一级；最高级（大西瓜）不再合成 | P0 | 两个同级水果相撞后原两颗消失、生成 1 颗高一级水果；11 级相撞不产生新水果 |

### V3 非功能要求

- 性能预算：中端真机稳定 60fps；单局水果实例数上限 120（超出视为异常并记录告警）。
- 物理稳定性：圆碰撞 + 连续碰撞检测（CCD）+ 限速 + 睡眠阈值；不得出现持续抖动或穿隧（GDD §13）。
- 存档与兼容：本地存档带 schema 版本号，旧版本可迁移；损坏存档回退默认值不崩溃。
- 网络与离线：MVP 全离线可玩；广告与分享为可降级的外部依赖，缺失时游戏仍可完整游玩。
- 可访问性与本地化：中文界面；圆角 UI；色弱可辨（水果颜色 + 半径双重区分）。
- 合规：隐私政策页、实名/防沉迷入口说明、适龄提示；不接支付。

## 操作与交互

| 场景 | 输入 | 行为 | 反馈 | 失败或边界行为 |
|------|------|------|------|----------------|
| 对局·瞄准 | 按住屏幕 | 显示落点预览线与反弹预演 | 预览线出现 | 按住不动仅显示预览，不消耗水果 |
| 对局·拖动 | 水平拖动 | 落点 x 跟随手指 | 预览线随手指移动 | 超出场地 x 范围时夹到边界，不越界 |
| 对局·投放 | 松手 | 在落点 x 生成当前水果 | 生成瞬间震屏 0.05s + 松手音 | 松手位置即最终落点；生成后进入冷却直到可再次瞄准 |
| 对局·合成 | 同级碰撞 | 合成高一级并加分 | 吸附 60ms → 粒子 → 慢放 → 顿帧 → 飘字 | 11 级相撞只产生碰撞反馈，不合成、不加分 |
| 对局·失败 | 静止水果越线满 1.2s | 进入失败流程 | 警戒线红色脉冲 + 心跳音 + 重震 0.2s | 越线后回到线下则计时清零 |
| 对局·复活 | 失败页点复活 | 播放激励视频，成功则清除最高一簇并续玩 | 广告播放 UI → 清除反馈 | 已用 1 次 / 全局冷却 90s 内 / 广告失败时按钮禁用并说明 |
| 对局·道具使用 | 点两侧入口后选点 | 按道具类型作用于场地 | 落点圈 + 生效特效 | 数量为 0 时不可用；瞄准中可取消 |
| 结算 | 失败或主动结束 | 显示分数、最高分、排行、分享挑战、再来一局 | 结算页 + 可选插屏 | 插屏按 V2.16 频次与开关决定是否出现 |
| 首次启动 | 启动完成 | 弹出隐私政策 | 隐私弹窗 | 不同意则停留并禁用上报/SDK，可退出 |
| 设置 | 点 HUD 齿轮 | 打开设置面板 | 面板与开关 | 开关即时生效并持久化 |
